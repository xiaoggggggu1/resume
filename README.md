# 张小可 · 互动个人求职主页

按《用 Workbuddy 打造互动个人求职网页》的流程完成：素材 → 首屏视频互动 → 内容填充 → 可预览网站。
纯静态站点（HTML + CSS + 原生 JS），无需构建，直接打开或任意静态服务器即可预览。

## 目录

```
index.html              单页结构（首屏 / 关于我 / 能力与兴趣 / 实践 / 履历 / 联系）
assets/styles.css       设计系统与响应式
assets/app.js           视频状态机、中英切换、滚动动画、复制、菜单
assets/hero-poster.jpg  首屏静态背景（视频首帧放大版）
assets/greet-poster.jpg 问候视频的静态首帧，避免切换闪白
assets/hero-working.mp4 素材 7：打字 + 标题逐字出现（第一段）
assets/hero-loop.mp4    由上一段尾部 0.68s 做首尾镜像，得到无缝「打字待机」循环
assets/hero-greet.mp4   素材 8：抬头、微笑挥手、向下指（互动段）
assets/portrait.jpg     关于我板块人像
```

## 首屏互动逻辑

1. 进页面静音自动播放 `hero-working.mp4`：标题「你好，我是张小可。」逐字出现。
2. 播完不重新打字，切到 `hero-loop.mp4`（标题已完整的尾部循环），保持打字待机。
3. 点击人物画面 / 「打个招呼」按钮 / 按 `H` → 播放 `hero-greet.mp4`：抬头看镜头、挥手、向下指。
4. 播放进度过半（约指向下方时）浮出「向下探索 ↓」，点击平滑滚动到「关于我」。
5. 问候结束自动回到待机循环；播放期间不可重复触发。
6. 系统开启「减少动态效果」时只展示静态首帧；视频不可播放时仍保留完整首屏与按钮。

> 说明：循环使用独立片段而非 `currentTime` 跳转，是因为部分静态服务器不支持 Range 请求，
> 视频无法 seek（会跳回 0 秒），独立片段方案在任何环境下都能稳定循环。

## 内容与替换

- 所有文案来自简历原图，未新增虚构经历、作品或奖项；区块按「实践与成果」重组。
- 修改文案：直接改 `index.html` 中带 `data-i18n` 的元素（中文为默认值），英文在 `assets/app.js` 的 `EN` 对象里。
- 换人像：替换 `assets/portrait.jpg`；换视频：保持同名覆盖即可（首屏为 16:9）。
- 联系方式在 `.contact` 区块，`data-copy` 属性控制点击复制的内容。

## 设计要点

- 配色取自素材本身：桌面黄 `#F0C020`、墙面色 `#EFEAE1`、墨黑 `#17150F`、绿植绿 `#2C5B45`。
- 首屏页面底色与视频墙面同色，16:9 素材不裁切、不拉伸，视觉上接近通栏沉浸。
- 标题只来自视频内的手绘字，页面不重复叠字；其余信息用排版承担层级。
